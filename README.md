# Aandpur Learning Platform v2 — UI Starter

A fresh, standalone HTML/CSS/JavaScript UI starter for Aandpur. It does not modify the original project.

## Current screens
- `index.html`: portal landing page
- `student/dashboard.html`: student dashboard UI
- `admin/dashboard.html`: admin dashboard UI

## Included
- Responsive left sidebar
- Light/dark theme toggle (saved in browser localStorage)
- Mobile sidebar toggle
- Student and admin dashboard layouts
- Placeholder interactions for features planned for later phases

## Run locally
Open the `aandpur-learning-platform-v2` folder in VS Code. Use Live Server and open `index.html`.

## Important
This is the UI foundation only. Login, real data, CRUD, and role-based security are not connected yet. The next phase should create a new Supabase project, database schema, authentication, and Row Level Security policies. Do not use the dashboard placeholder as production admin security.
